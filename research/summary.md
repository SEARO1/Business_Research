## 🎓 Key Insights

### 1. Jenkins is the #1 CI/CD Pain Point
- Eventbrite: 90 min/developer/week downtime
- Dollar Shave Club: Single spec files to avoid breaking suite
- Tunaiku: Jenkins required week to set up new project
- RepairPal: Jenkins had "plenty of frustrations"
- Bolt: "We don't want to build something that's not core"
- Baracoda: "One teammate was running Jenkins in the morning, checking, breaking everything"

### 2. Security/Compliance is a Massive Tax
- Vendor security reviews: 100hrs × 50+ vendors = 5,000+ hrs/year
- Manual compliance: 2,000+ hrs/year at enterprises
- GRC teams maintaining 12+ frameworks with 2 people
- Identity inventory: 480k impossible manually, unused = attack vector

### 3. M&A Creates Identity Nightmares
- 6 months per acquired company on-prem identity integration
- Hitachi:100 AD servers, each a patch/replication/DR burden
- Okta M&A integration is a key use case

### 4. CI/CD Speed is Competitive Advantage
- Goldman Sachs: 1 build/2 weeks → 1000+/day
- Lockheed Martin: 80x faster CI, 1000s Jenkins servers retired
- Deutsche Telekom: 18 months → 3 months release cycles
- Hilti: 12x faster deployment, 400% more code checks

### 5. Tool Sprawl Costs Big
- 76-country, 160k-employee Saint-Gobain: data silos everywhere
- 10+ disconnected spreadsheets per GRC framework
- Brex: 70% cost reduction + 3x faster movement via consolidation
- Jira + Atlas + Monday.com + spreadsheets = roadmap blindness
